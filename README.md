## Featured Projects

### 🏠 [Madrid Housing Price Prediction](https://github.com/CharlieSm49/madrid-housing-ml)

**Python • Pandas • NumPy • scikit-learn • Jupyter**

Machine-learning project using two Madrid City Council datasets covering 130 neighbourhoods and 15 socioeconomic indicators.

- Cleaned, standardised and merged real-world datasets
- Resolved inconsistent neighbourhood records and other data-quality issues
- Built and evaluated a Linear Regression model
- Used MAE, MSE, RMSE and R² to assess performance
- Achieved an R² score of **0.85**
